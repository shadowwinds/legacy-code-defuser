# 06 · 桌面化叙事壳 (Desktop Shell)

> v1.0.0 计划定稿(2026-10-24,地图 #15 汇总)。**本章是计划**:描述 v1.1「桌面化」里程碑做什么、按什么标准验收;实现派工见 `docs/desktop/execution-plan.md`。

## 6.1 范围与定位

把「Windows 桌面」作为叙事壳包在 Excel 外层,地位 = **氛围 + 轻度钩子**(词条见 `GLOSSARY.md`):

- **桌面壳** = 壁纸 + 桌面图标 + 任务栏 + 聊天浮层 + Toast + 开场动画
- **轻量窗口**(ADR-0002):Excel 永远独占全屏,聊天为浮层 + 任务栏图标收起 + 红点;**不做窗口管理器**(无拖拽/遮挡/聚焦)
- 聊天**不承载解谜必需信息**(硬线索只在 Sheet2 手册);可在关键事件主动打断(心理压力,无机制惩罚)
- 占位 App 彩蛋(回收站/扫雷内容)不进本里程碑

## 6.2 任务栏与时钟

- 开始按钮 + 应用图标(Excel 运行中蓝条 / 企业微信未读红点)+ 右下角 **16:5X 实时时钟**
- 时钟与 240s 全局引信同源(16:56:00 → 17:00:00),是「双时间轴」的桌面侧表达;玩家不看表格状态栏也知道下班在逼近
- 视觉基线:`docs/desktop/proto.html` 场景 B/D(原型票 #18,用户过目后定稿截图贴回)

## 6.3 聊天系统与触发面

- **会话列表**:甲方老张(暴躁金主,主发)/ HR 小陈(圆滑补刀 1–2 条/局)/ 老王(已拉黑,消息一律「被对方拒收了」)
- **玩家不发言**:仅「已读」回执与「对方正在输入…」状态条(沉默牛马人设)
- **文案源**:`docs/desktop/dialogues.json`(契约 `dialogue-contract.md`,schema 机器校验 `validate-dialogues.mjs`;当前为 agent 代拟占位,可由 DeepSeek 提示词包 `deepseek-prompt.md` 量产替换)
- **触发面**:局内推送挂事件锚为主、时间锚兜底(见 §6.5);**结局锚**映射引擎 `endReason` 现有 4 条路径 × 凶手模块 = 7 组:

| 结局锚 | endReason | 组 |
| :--- | :--- | :--- |
| row1–row5 | 「{跨部门汇总/防欠薪网关/乱码考古/平账脚本/重启仪式} 当场爆炸。」 | 凶手模块分组,row4 突出账目/钱,row5 突出「又双叒挂了」 |
| fuse | 「17:00 了,引信烧完,全表爆炸。」 | 引信组 |
| win | 「17:00 准点跑路,下班!」 | 胜利组 |

## 6.4 开场动画(回忆杀)

- 形态:回忆杀分镜(老王甩文档 → 你提问 → 被拉黑),黑场字幕 + 对话气泡拟物,总阅读时长 ≤25s
- **首次进站播放一次、点击任意处跳过**;收尾「双击 Excel」脉冲图标 → 白闪 → 无缝进 ExcelShell
- 分镜文案:`dialogues.json` `sb_*` 10 条(174 字);分镜骨架与转场示意见 `proto.html` 场景 A
- 跳过补位:跳过后 8s 内无事件锚触发则播 system 补位条(pacing §5)

## 6.5 事件锚节奏表

完整三列表(锚点 → 消息 → 物理表现)见 `docs/desktop/pacing.md`;要点:

- **打断三档**:A 强打断(toast 6s + urgent)/ B 弱打断(4s + ding)/ C 仅红点;入场动画统一 200ms,目标「可无视但不失压迫」
- **节流**:每局 toast ≤6 条;15s 窗口最多 1 条,超出自动降 C 档;0:00–0:40 熟悉期 0 条新推送(系统播报除外)
- 已知错位(留 playtest):Row5 首次假死 45s 落在熟悉期末,早于 §3.2 高压期预期
- 结局顺序:结局组气泡 400ms/条连环吐入 → 0.8s 后 EndOverlay 淡入 → 弹窗下聊天可回看不可交互

## 6.6 消息提示音

- 复用嘀嗒声引擎模式(Web Audio 合成,零音频文件):`ding`(B 档)/ `urgent`(A 档)两条短音,音量 ≤ 嘀嗒
- 🔊 静音按钮对全部音效生效(既有)

## 6.7 验收标准

1. 开局 ≤25s 完成回忆杀或跳过,转场无白屏断裂;二局不再播
2. 局内 toast 密度符合 §6.5 节流;玩家全程可无视推送完成通关(无机制惩罚)
3. 7 组结局对话按凶手模块正确触发;老王消息永远显示「拒收」
4. 任务栏时钟与引擎引信同步走;Excel 全屏时聊天收起为图标
5. 心流:真人试玩打扰度记录 ≥2 局后按 pacing §6 定稿(pacing 票 #19 收口)
6. 全 CSS/SVG 零美术资产;生产包零音频文件;中文 UI
