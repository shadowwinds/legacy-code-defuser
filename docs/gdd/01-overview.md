# 01 · 项目概述 (Overview)

## 1.1 主题 / 背景 / 类型

* **主题**：祖传代码维护 (Legacy Code) × 职场黑色幽默。
* **背景**：周五下午 16:56 的互联网公司工位。前任架构师老王刚办完离职手续并拉黑了所有人，公司核心生产环境的监控被老王做成了一张通过 VBA 宏连进服务器的 Excel 表——《核心业务_最终版_打死勿动.xlsx》。距离 17:00 封网下班只剩 4 分钟，全表开始连环报警。
* **类型**：策略解谜 / 查手册拆弹 (Puzzle) / 职场黑色幽默模拟器。

## 1.2 核心玩法简述

* **双层致命倒计时**：全局「下班引信」240s（时钟从 16:56:00 走到 17:00:00）+ 5 个祖传模块各自的局部毁灭倒计时。
* **查手册 → 操作**：所有解法写在 Sheet2 的《离职交接文档》里。`Tab` 全屏切换「表格 ↔ 手册」，切换时游戏照跑——你必须**记住**步骤再切回来操作，记忆压力是 KTaNE 的灵魂。
* **5 行 5 种交互面**：下拉选择 / fx 公式栏改代码 / 跨 Sheet 查表 / 底部状态栏凑数 / 周期事件应对——整个 Excel UI 都是解谜界面。
* **耦合蝴蝶效应**：模块之间存在写入手册的硬耦合，拆 A 会连坐 B。
* **无老板键**（v2.0 砍掉）：键盘只剩 `Tab`，「摸鱼伪装」降级为纯皮肤卖点。

## 1.3 目标平台

PC Web 浏览器（16:9 全屏体验最佳），纯前端单页应用，部署于 GitHub Pages。

## 1.4 商业化模式

免费开源 Demo / 黑客松参赛作品，无内购，无广告。

## 1.5 项目规模

* **成本**：0 元。纯前端开发，零外部美术资产，全靠 CSS/SVG 还原 Excel UI。
* **周期**：48 小时极限 Demo。
* **团队**：1 人 + AI 结对编程助手。

## 1.6 灵感来源

* **《Keep Talking and Nobody Explodes》**：核心骨架——「面对黑盒炸弹 + 对照一本写满反人类规则的手册 + 倒计时归零前完成判定」。
* **《Papers, Please》**：在枯燥的办公桌面上进行高强度信息核对的沉浸感。
* **Excel 离职交接梗文化**：删一行注释全公司停摆、`final_final_v3`、合并单元格万恶之源等真实痛点。

## 1.7 电梯演讲

> 一款伪装成正经 Excel 表格的硬核「祖传代码拆弹」游戏。你必须在下班引信烧完之前，靠背下前任留下的《离职交接文档》，通过拉宽列宽、手改公式、给状态栏凑求和这些离谱但无比真实的 Excel 操作，拆掉 5 个耦合在一起的祖传模块——全部拆完立即下班，差一个或者拖到 17:00，全表爆炸。

## 1.8 与 KTaNE 的关键差异

| | KTaNE | 本作 |
| :--- | :--- | :--- |
| 手册 | 纸质/第二屏，随时可看 | Sheet2 全屏切换，看表时看不到手册 |
| 炸弹 | 固定面板 | 每局参数随机的 Excel 表 |
| 信息载体 | 指示灯、电线、序列号 | 条件格式、批注、fx 栏、状态栏、列宽 |
| 失败 | strikes 3 次 | 无 strikes：错误操作直接扣倒计时，归零即死 |
| 胜利 | 拆完当前炸弹 | 拆完 5 个模块立即下班 |

## 1.9 项目详述

你以为打开的是一张普通的办公表格，实际上这是一个随时会引爆公司服务器的代码雷区。表格里的 5 个可交互祖传模块各自拥有独立倒计时，以 Excel 条件格式数据条的形式肉眼可见地燃烧。

盲目操作活不过一分钟：这些祖传代码高度耦合，对账脚本失衡超过 10 秒，下游两个模块的倒计时就会被脏数据冲掉 15 秒；重启仪式每次成功，都会随机反噬一个还没拆的模块。

玩家必须像真正的拆弹专家一样：观察症状 → `Tab` 切到 Sheet2 背下对应小节的黑话规则 → 切回表格执行。线索藏在 Excel 最原生的载体里——右下角状态栏的求和、被 `####` 藏住的列、`45296.5` 这种鬼才知道是日期的数字、以及 `fx` 栏里那句 `// 生产环境定时自爆，防拖欠尾款`。

当全场飘红、引信只剩最后 30 秒时，你还有两个 Excel 老手的糊弄学大招：【格式刷】把红行强刷成绿色（掩耳盗铃），【冻结窗格】物理暂停倒计时 8 秒。拆完全部 5 个模块的瞬间，屏幕弹出经典的「是否保存对『核心业务.xlsx』的修改？」——点【不保存，直接跑路！】，通关。
