# 02 · 核心机制详解 (Core Gameplay Mechanics)

## 2.0 差异化亮点 (What Sets This Apart)

1. **100% 纯正的 Excel 拟物交互**：没有任何违和的游戏 UI——血条是条件格式数据条，技能栏是 Ribbon，线索是批注、`fx` 栏和 Sheet2 手册，连解谜操作都是拉列宽、切数字格式这种真实 Excel 动作。
2. **「循环引用」式蝴蝶效应**：程序员最痛恨的代码强耦合，映射为 Excel 的跨单元格引用与追踪箭头。
3. **5 行 5 种互不重复的交互面**：下拉 / fx 公式栏 / 跨 Sheet 查值 / 底部状态栏 / 周期事件——玩家每拆一个模块都在学一种新的 Excel 视角。
4. **查手册的记忆压力**：手册和炸弹永不同屏，切手册时倒计时照跑，嘀嗒声是唯一的时间线索。

## 2.1 双层倒计时与胜负判定

* **全局引信**：240s，界面显示为时钟 `16:56:00 → 17:00:00`。烧完 = 全表爆炸（Game Over）。
* **局部倒计时**：5 个可交互模块各自独立倒数，以 E 列数据条呈现。任一归零 = 当场爆炸（Game Over）。
* **无 strikes**：错误操作不累计次数，直接扣除对应倒计时——惩罚即反馈。
* **数据条状态色**（复刻 Excel 条件格式）：

| 剩余时间 | 颜色 | 表现 |
| :--- | :--- | :--- |
| > 60s | 绿底 `#C6EFCE` / 字 `#006100` | 正常倒数 |
| 20 ~ 60s | 黄底 `#FFEB9C` / 字 `#9C6500` | 单元格轻微闪烁 |
| < 20s | 红底 `#FFC7CE` / 字 `#9C0006` | 文本变 `#URGENT!`，<10s 抖动 |

## 2.2 核心循环：查手册 → 操作

`Tab` 全屏切换「Sheet1 表格 ↔ Sheet2 手册」，**切换时游戏照跑**。Sheet2 上看不到任何倒计时，只能听到嘀嗒声越来越急促。

标准循环：观察症状 → 切手册定位小节 → 背下条件句与步骤 → 切回表格执行 → 出错再查。手册用职场黑话写条件句，但**结构清晰**（每模块独立小节 + 附录对照表），保证查得到、背得住——坑的是翻译，不是排版。

| 行 | 模块 | 交互载体 | 初始倒计时 | 耦合 |
| :--- | :--- | :--- | :--- | :--- |
| Row1 | 跨部门汇总合并单元格 | 下拉选择 | 80s ±10% | 无（门槛模块） |

### Row1 · 跨部门汇总合并单元格 (MOD_MERGE)

* **遗留**：2014 / 某项目经理 · **故障**：`#结构损坏!`
* **背景梗**：合并单元格是 Excel 万恶之源——排序、筛选、公式全废。
* **机制**：F1 下拉菜单三选项：`[拆分并填充值]` / `[保留合并强行写入]` / `[合并后居中]`。
* **手册条件句（黑话版）**：「若 1.2 号网关尚处于自爆待解除状态，先对 1.1 执行【拆分并填充值】对齐颗粒度；否则【保留合并强行写入】即可闭环。」（正确选项随 Row2 状态动态变化，制造先查后点的压力）
* **选错**：Row1 倒计时 -20s。
* **隐藏陷阱**：`[合并后居中]` 是纯陷阱——手册只字未提，选了全场倒计时 -15s，并弹批注：「2014 年有人这么干过，这就是这张表长这样的原因。」

### Row2 · 防欠薪定时自爆网关 (MOD_PAYWALL)

* **遗留**：2016 / 某跑路外包 · **故障**：`#DEADLOCK!` 紫底白字，该行下拉全部置灰。
* **机制**：选中该行，`fx` 栏显示：

```text
=IF(ENV="PRODUCTION", CRASH_NOW(), "SAFE")  // 生产环境定时自爆，防拖欠尾款
```

* **解法**：点进 `fx` 栏手动把 `"PRODUCTION"` 改成 `"LOCALHOST"`（寓意：在我本地是好的），回车 → 死锁解除，倒计时回满，模块标记已拆。
* **进阶彩蛋**：在最外层套 `=IFERROR(原公式, "200 OK")` 同样有效，额外弹批注：「糊弄学大师。」
* **定位**：全游戏操作量最小、梗密度最高的模块，通常作为玩家建立信心的第一杀。

### Row3 · 乱码考古·口令验证 (MOD_MOJIBAKE)

* **遗留**：2015 / 已离职老王 · **故障**：D3 显示 `####`（列宽不够）。
* **三阶段解法**（纯 Excel 原生操作）：
  1. **拉宽列宽**：拖拽 D/E 列分界线，`####` 显形为 `45296.5`——Excel 把口令日期自动转成了序列值。
  2. **切数字格式**：顶部格式下拉从「常规」切到「短日期」，还原出真实日期（即口令提示）。
  3. **跨 Sheet 查表**：切到 Sheet2 附录A《乱码对照表》，找到本局随机分配的日期 ↔ 口令映射，把口令填回指定单元格。
* **填错**：单元格变 `#VALUE!` 且倒计时锁定在 5s——必须重新查表填对才能解锁（给查表错误一个极痛的代价）。
* **随机性来源**：每局口令映射从附录 5 行中随机选 1 行生效。

### Row4 · 财务对账平账脚本_勿动 (MOD_RECON)

* **遗留**：2019 / 隔壁组甩锅 · **故障**：`#DIV/0!`，底部状态栏 `求和: ≠1024`。
* **机制**：G 列预置一堆被祖传浮点精度 Bug 污染的垃圾数据。监控脚本只认一条铁律：**G 列求和 = 1024 时账平**。底部状态栏常驻实时显示「求和: N」。
* **解法**：在 G 列空格填数字凑够求和 = 1024（可以删垃圾数据，也可以加数）。
* **预期彩蛋**：直接在空格写 `=1024-SUM(G2:G9)` 偷懒过关——游戏检测到此公式，弹批注：「外包本人吧？」
* **批注遗言**：「兄弟，这脚本有祖传浮点精度 Bug，快炸的时候千万别改代码，凑数就行。——隔壁组 2019」
* **Edge A 源头**：失衡状态持续超过 10s → Row2/Row3 各 -15s。
* **定位**：唯一不看单元格看状态栏的模块，持续低压压迫感，适合开局先处理。

### Row5 · 拜机房神兽重启仪式 (MOD_RITUAL)

* **遗留**：2012 / 运维背锅侠 · **故障**：每约 45s 周期性进入 `#STUCK!` 假死（紫灰底）。
* **机制**：假死后 15s 内必须执行重启仪式（F5 下拉选 `[重启服务]`），成功则 Row5 倒计时回满。
* **Edge B 赌博**：仪式成功瞬间，随机 1 个**未拆**模块 -5s。重启就是赌博，老运维都懂。
* **超时未重启**：Row5 直接爆炸。
* **手册黑话**：「每逢假死，上香重启。重启必反噬，砸谁看祖师爷心情。心要诚，手要快。」
* **定位**：全场节奏打乱器——玩家正专心拆别家时它突然假死，逼你在「立刻放下手头操作」和「赌它撑得住」之间抉择。

## 2.4 装饰行（不可交互 · 氛围组）

| 行 | 模块 | 表现 |

| Row7 | final_final_v3 考古区 | 底部 Sheet 标签区多两个废标签：`最终版_勿用`、`真最终版(2)`，点击弹批注「考古现场。Sheet1 才是唯一真数据源」。手册前言同步声明 |
| Row8 | "别动它能跑"🐉 | 禁操行。任何点击/修改 → 全场倒计时 -30s。批注：「我不确定它为什么能跑，但删了它整个公司会停摆。——老王 2013」 |

Row7/Row8 承担「虚假可交互性」：长得能点，点了就痛，玩家通过试错和手册学会敬畏祖传代码。

## 2.5 耦合边（仅 2 条，写入手册第 4 节）

* **Edge A · 脏数据连坐**：Row4 失衡（求和 ≠ 1024）持续超 10s → Row2/Row3 各 -15s。
  * 选中 Row4 时显示红色追踪箭头指向 Row2/Row3。
* **Edge B · 重启是赌博**：Row5 仪式成功 → 随机 1 个未拆模块 -5s。
  * 反噬目标不预告，命中时该单元格闪一下。

> v1.0.0 的自由耦合图（8 行任意互绑）被收敛为这 2 条：耦合是**独有机制**但不是**核心玩法**，开发成本可控且手册写得完。

隐藏行 / 查找替换 → roadmap（见 05）。

## 2.7 随机性与重玩价值

**固定结构 + 参数随机**：

* Row3 口令映射：附录 5 行随机选 1 行生效。
* 各模块初始倒计时：±10% 抖动。
* 平账目标固定 1024，不追加随机轴（待 playtest 再议）。

模块身份、耦合边、手册结构每局固定——重玩变的是参数，玩家第二次玩时依然要查表，但查得更快，形成「背手册」的成长感。
