## Revision History

### 2.0.0 (2026-10-24) — KTaNE 化重构

在 v1.0.0（单文件 GDD，8 行祖传代码 + 老板键摸鱼流）基础上，方向变更：

- **核心循环重构**：从「多轨倒计时续命挂机」改为 KTaNE 式「查手册 → 操作」解谜循环。`Tab` 全屏切换「表格 ↔ Sheet2《离职交接文档》」，切换时游戏照跑，记忆压力是体验核心。
- **胜利条件重构**：拆完全部 5 个模块**立即获胜**（不再是纯挂机撑到 17:00）。
- **老板键砍掉**：`Space` 老板键移除，键盘只剩 `Tab`；「摸鱼伪装」降级为纯皮肤卖点。
- **阵容重构**：8 行全可交互 → **5 个可交互模块 + 3 个装饰行**；5 个模块对应 5 种互不重复的 Excel 交互面（下拉 / fx 公式栏 / 跨 Sheet 查值 / 底部状态栏 / 周期事件）。
- **引入 Excel 原生操作解谜**：拉宽列宽、切换数字格式、状态栏求和——整个 Excel UI 都是解谜界面。
- **耦合机制收敛**：自由耦合图 → 仅 2 条明确写入手册的耦合边。
- **技能收敛**：4 个 Ribbon 技能 → 2 个（格式刷、冻结窗格），其余进 roadmap。
- **随机性定调**：固定结构 + 参数随机（口令 5 选 1、倒计时 ±10% 抖动）。
- 无 strikes 机制：错误操作 = 倒计时惩罚（扣时），归零即爆炸。
- 未定的实现细节一律标注「待 playtest」。
