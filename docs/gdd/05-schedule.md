# 05 · 里程碑 (Schedule)

48 小时极限 Demo，5 个里程碑串行推进。

## Milestone 1 · 视觉外壳

1:1 高仿 Excel 2016 界面。

- [ ] 标题栏 / Ribbon / fx 公式栏 / 网格 / 底部状态栏 / Sheet 标签栏
- [ ] 单元格选中高亮 + 拖拽块、行点击选中
- [ ] 红三角批注悬浮框
- [ ] `Tab` 全屏切换 Sheet1 ↔ Sheet2 骨架（切换时引擎照跑）
- [ ] 数据条（条件格式三色）静态渲染

## Milestone 2 · 倒计时与耦合引擎

- [ ] `useGameEngine` 100ms 状态机：全局引信 240s（时钟 16:56→17:00）+ 5 局部倒计时
- [ ] ±10% 初始抖动随机器
- [ ] 数据条随剩余时间变色/闪烁/抖动
- [ ] 底部状态栏实时求和（Row4 交互面）
- [ ] SVG 追踪箭头（选中行显示耦合边）
- [ ] 惩罚结算管线（扣时、锁定、全场-15s 等）

## Milestone 3 · 拆弹交互与手册

- [ ] Row1 下拉条件判定 + 合并后居中陷阱
- [ ] Row2 fx 栏改 `ENV` + `IFERROR` 彩蛋检测
- [ ] Row3 三阶段：拉列宽 → 切数字格式 → 附录 5 选 1 查表填口令
- [ ] Row4 凑求和 1024 + `=1024-SUM()` 偷懒公式彩蛋 + Edge A 失衡连坐
- [ ] Row5 周期假死/重启仪式 + Edge B 随机反噬
- [ ] Sheet2《离职交接文档》全文渲染（含附录对照表）
- [ ] 格式刷 / 冻结窗格两技能 + CD
- [ ] 装饰行 Row6/7/8（含 Row8 -30s 禁操惩罚）
