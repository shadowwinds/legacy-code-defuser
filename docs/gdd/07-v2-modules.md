# 07 · v2.0 模块规则与外壳变量（「每局都得查手册」）

> 地图 #39 的模块规格，由模块阵容与规则重设计票 #45、外壳变量清单票 #44、崩出 Excel 高潮票 #47 定稿（2026-11-04）。**本章是规格**，实现票按本章开工。手册全文（Sheet2）由「手册重写」#46 按本章改写。
>
> 数值一律「待 playtest」；**碰撞率**是硬验收（见 §7.5）。

## 7.1 设计骨架

每局的变化分三层（地图已钉决策 6，修订版）：

1. **模块自身随机外观**（主力）：报错码、守卫变量、口令日期、垃圾数据、状态栏统计方式。
2. **外壳变量**（开关）：只以「一眼可判的谓词」出现在规则里。
3. **局内实时状态**（补充）：例如 Row5 假死这一事件本身。

手册写法沿用 KTaNE 调研原则（`docs/research/ktane-rule-design.md` §6）：

- 每节先「**按可见特征分节**」，再「**首条命中**」，最后「**兜底**」。
- 黑话只写在导语和附录里，条件句平实、无歧义。
- 读外壳的小节开头交叉引用「附录 C · 去哪找」。

## 7.2 外壳变量

| 代号 | 变量 | 取值 | 位置 | 谓词 |
| :- | :- | :- | :- | :- |
| V | 版本号 | `核心业务_最终版_v{N}.xlsx`，N ∈ 2–29 均匀 | 标题栏 | 末位单数？ |
| M | 宏警告条 | 有 / 无：「⚠ 安全警告 宏已被禁用【启用内容】」 | 公式栏上方黄色条 | 有没有 |
| W、N | 时间场景 | 4 选 1，见下表 | 任务栏时钟与日期 | 周末？深夜？ |
| P | 日期 | 1–28 号，并与场景的星期在日历上对得上 | 任务栏日期 | 过了 15 号？ |
| A | 作者 | 6 选 1：老王 / 外包-张三 / 实习生小李 / Administrator / AutoSave / 甲方 | 【文件 → 信息】 | 是不是外包-张三 |

时间场景（全局引信总是从截止前 4 分钟走到截止时刻，240 秒不变）：

| 场景 | 截止时刻 | W 周末 | N 深夜 |
| :- | :- | :- | :- |
| 下班封网 | 周五 17:00 | 否 | 否 |
| 发版窗口关闭 | 周三 22:00 | 否 | 是 |
| 甲方周末验收 | 周六 10:00 | 是 | 否 |
| 例会前夜 | 周日 24:00（周一 00:00） | 是 | 是 |

**噪声字段**（不被任何规则引用，都放在【文件 → 信息】里）：文件大小、修订次数、最后修改时间、公司、标记。

种子派生：每个变量单独用一条随机流 `shell:<变量名>`，均匀分布。

## 7.3 五个模块

### Row1 · 跨部门汇总合并单元格（下拉）

- **外观**：A1 的报错码随机 5 选 1，替换 v1 固定的 `#结构损坏!`。
- **F1 下拉**：5 个合法选项，加上陷阱选项【合并后居中】（规则与 v1 相同：全场 -15 秒，并弹出 2014 年的批注）。
- **规则**：按报错码分节，每节只有一个外壳开关。

| A1 报错码 | 开关 | 否 | 是 |
| :- | :- | :- | :- |
| `#结构损坏!` | 有宏警告条？ | 拆分并填充值 | 拆分不填充 |
| `#合并冲突!` | 版本号末位单数？ | 保留合并强行写入 | 拆分并填充值 |
| `#排序失败!` | 周末？ | 跨列居中 | 转为表格 |
| `#筛选失效!` | 深夜？ | 转为表格 | 保留合并强行写入 |
| `#引用断裂!` | 过了 15 号？ | 拆分不填充 | 跨列居中 |

- **碰撞率**：每个答案恰好出现 2/10，碰撞率 = **20%**。
- 选错：本行 -20 秒（同 v1）。v1 里「看 Row2 是否已拆」的条件**删除**，因为它由玩家的操作顺序决定，实测碰撞率会到 62.5%。

### Row2 · 防欠薪定时自爆网关（fx 公式栏）

- **外观**：守卫变量随机 5 选 1，公式形如 `=IF({守卫}="{危险值}", CRASH_NOW(), "SAFE")  // {外包注释}`。
- **解法**：在 fx 栏里把危险值改成「骗它的值」，回车。

| 守卫 | 危险值 | 平日 | 周末 |
| :- | :- | :- | :- |
| `ENV` | `"PRODUCTION"` | `"LOCALHOST"` | `"STAGING"` |
| `PAYDAY` | `"未结清"` | `"已结清"` | `"下周结"` |
| `CLIENT` | `"甲方"` | `"自己人"` | `"老板亲戚"` |
| `REGION` | `"PROD-CN"` | `"DEV-HOME"` | `"MARS"` |
| `BUILD` | `"RELEASE"` | `"DEBUG"` | `"SNAPSHOT"` |

- **IFERROR 彩蛋**：在最外层套 `=IFERROR(原公式, "200 OK")` **只在「有宏警告条且作者是外包-张三」时有效**，生效时弹批注「糊弄学大师。」。其他情况下按改错处理。如果只看宏警告条，「永远套 IFERROR」的成功率是 50%，加上作者条件后降到 8.3%。
- **碰撞率**：10 种答案均匀分布，碰撞率 = **10%**。照搬 IFERROR 的成功率为 8.3%。

### Row3 · 乱码考古·口令验证（列宽 → 格式 → 查表）

- **外观**：口令日期从附录 A 的 **12 行**里随机抽 1 行（v1 是 5 行）。
- **三阶段**同 v1：拉宽 D 列，`####` 变成序列值；切换到「短日期」，显示日期；查附录 A 得到口令。
- **新增开关**：版本号末位单数时，口令填在 **F3**，双数时填在 **H3**。填错位置按填错处理（`#VALUE!` 并锁 5 秒）。
- **碰撞率**：12 × 2 种，碰撞率 = **4.2%**。这是必查型模块。

### Row4 · 财务对账平账脚本_勿动（状态栏凑数）

- **外观**：G 列垃圾数据每局随机；状态栏统计方式随机为 **求和** 或 **平均值**（Excel 状态栏原生就会显示其中之一）。
- **目标值**按时间场景决定：

| | 白天 | 深夜 |
| :- | :- | :- |
| **平日** | 1024 | 2048 |
| **周末** | 996 | 404 |

- **规则**：状态栏显示什么统计，就让那个统计等于目标值。偷懒公式彩蛋 `=目标-SUM(...)` 只在求和模式下有效。
- **Edge A** 同 v1：失衡超过 10 秒，Row2、Row3 各 -15 秒。
- **碰撞率**：4 × 2 种，碰撞率 = **12.5%**。这是可背型模块。

### Row5 · 拜机房神兽重启仪式（周期事件）

- **外观**：假死时 F5 显示的报错码随机 5 选 1；首次假死时刻每局在 35–55 秒之间随机（v1 固定 45 秒）。
- **规则**：在 15 秒窗口内从下拉里选对仪式。

| F5 报错码 | 开关 | 否 | 是 |
| :- | :- | :- | :- |
| `#STUCK!` | 周末？ | 重启服务 | 上香 |
| `#TIMEOUT!` | 有宏警告条？ | 拔网线 | 清缓存 |
| `#OOM!` | 版本号末位单数？ | 清缓存 | 回滚到昨天 |
| `#EPIPE!` | 深夜？ | 拔网线 | 上香 |
| `#HANG!` | 过了 15 号？ | 回滚到昨天 | 重启服务 |

- 选错：本行 -10 秒，仍在窗口内可以重试（待 playtest）。超时未选对：爆炸（同 v1）。
- **Edge B** 同 v1：仪式成功时，随机一个未拆模块 -5 秒（目标由种子决定）。
- **碰撞率**：每个答案 2/10，碰撞率 = **20%**。v1 的原稿规则枚举出来是 34%，已改为本表。

### 不变

- 装饰行 Row6、Row7、Row8 不变。
- 两个 Ribbon 技能（格式刷、冻结窗格）不变。

## 7.4 可背型与必查型

| 类型 | 模块 | 手册形态 |
| :- | :- | :- |
| 可背型 | Row1、Row4、Row5 | 5 行小表或 2×2 表。几局后玩家能背下**规则**，但每局的答案仍然要看外观和外壳 |
| 必查型 | Row2、Row3 | 10 格守卫表、12 行口令表，老手也得翻 |

## 7.5 碰撞率验收（硬指标）

- **定义**：照搬上一局某模块的答案，在本局仍然正确的概率，等于 Σpᵢ²。
- **验收**：每个模块 ≤ 20%。
- **测法**：引擎层模拟器测试。用 1000 个种子各生成一局，调用各模块的纯函数 `answerFor(局面)` 算出正确答案，统计相邻两局答案相同的比例，断言 ≤ 0.2（允许抽样误差，阈值取 0.22）。
- 本章各表的理论值都由枚举脚本核对过：Row1 20% / Row2 10% / Row3 4.2% / Row4 12.5% / Row5 20%。
- 首局通关率约 30% 仍需真人试玩验证。

## 7.6 崩出 Excel 的高潮（#47）

活表格（L0–L3，见 GLOSSARY「活表格」）之上，再加三个时刻：

1. **最后 30 秒**：全局引信 ≤ 30 秒，或任一未拆模块 ≤ 10 秒。错误值漏出表格：
   - 先感染 Ribbon 上的装饰占位块和公式栏右侧空白，再越过窗口下缘爬到桌面壁纸和桌面图标上。
   - **可交互区域永远不盖**：技能按钮、F 列下拉、fx 输入、口令输入框、Sheet 标签。
   - 纯演出，`pointer-events: none`。
2. **爆炸瞬间**：Excel 窗口碎裂掉落（约 1.2 秒），露出类似蓝屏的「核心业务.xlsx 已停止工作」，然后按 GDD 06 §6.5 的时序依次出现结局对话气泡和 Win98 弹窗。
3. **通关瞬间**：倒放。错误值从桌面缩回表格，整表刷成绿色，再弹出「是否保存」。
